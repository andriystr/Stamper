# Stamper

Тренажер для запам'ятовування тексту. Ви створюєте картку з одним або кількома текстами, потім відтворюєте текст по пам'яті, а застосунок позначає відмінності червоною ручкою. Дані зберігаються у вашому браузері, нічого не надсилається на сервер.

Застосунок: <https://andriystr.github.io/Stamper/>. Його можна встановити як PWA і користуватися офлайн.

## Запуск локально

Потрібен будь-який статичний сервер, наприклад:

```sh
python3 -m http.server 8000
```

і відкрийте <http://localhost:8000>. Файл `index.html` напряму через `file://` працює гірше: IndexedDB і service worker потребують http(s).

## Тести

Тести запускають застосунок у Chromium через Playwright.

```sh
npm install
npx playwright install chromium   # якщо браузера ще немає
npm test
```

Сервер для тестів (`tests/static-server.js`) піднімається автоматично.
