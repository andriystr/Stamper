# Stamper

Тренажер для запам'ятовування тексту. Ви створюєте картку з одним або кількома текстами, потім відтворюєте текст по пам'яті, а застосунок позначає відмінності червоною ручкою. Дані зберігаються у вашому браузері, нічого не надсилається на сервер.

Застосунок: <https://andriystr.github.io/Stamper/>. Його можна встановити як PWA і користуватися офлайн.

## Як користуватися

- Картки з'являються в меню, на кожній видно кількість текстів.
- У тренажері пишіть текст по пам'яті. Слово — це один токен, кожен розділовий знак — окремий токен, пробіли лише розділяють. Щойно слово або знак завершено (введено пробіл або наступний токен) і він не збігається з оригіналом, він стає червоним, і далі друкувати не можна: тільки **Backspace**, який прибирає весь неправильний токен. Апострофи («’», «'», «ʼ») і тире («-», «–», «—») вважаються однаковими; слово через тире — один токен. На телефоні, де це підтримується, є короткий сигнал вібрацією.
- «Перевірити» або **Ctrl+Enter** (Cmd+Enter на macOS) показує весь текст із червоною ручкою. Лічильник «N з M» показує, який текст зараз.
- Видалення картки чи тексту спершу питає підтвердження.

## Запуск локально

Потрібен будь-який статичний сервер, наприклад:

```sh
python3 -m http.server 8000
```

і відкрийте <http://localhost:8000>. Файл `index.html` напряму через `file://` працює гірше: IndexedDB і service worker потребують http(s).

## Тести

Тести запускають застосунок у Chromium через Playwright.

```sh
npm install
npx playwright install chromium   # якщо браузера ще немає
npm test
```

Сервер для тестів (`tests/static-server.js`) піднімається автоматично.
